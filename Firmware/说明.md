# 已编译固件

本文件夹来自交付工程的完整 Keil Rebuild，Arm Compiler 5.06 update 7 build 960，0 错误、0 警告。

- UAVGarage_SBUS.hex：本次编译的烧录映像。
- UAVGarage_SBUS.axf：同次构建的符号与调试文件，应与对应 HEX 配套使用。
- UAVGarage_SBUS.map：链接映射。
- SHA256SUMS.txt：上述文件的 SHA256。
- build-manifest.json：编译记录与对应源码/工程配置校验值。

推荐从 MDK-ARM/UAVGarage.uvprojx 打开完整工程后 Rebuild、Download，以便使用同一次编译的调试符号。没有进行实物烧录或电机运行验证。操作参见 ../Docs/SBUS_使用教程.md。
